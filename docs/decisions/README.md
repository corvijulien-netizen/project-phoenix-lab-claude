# Décisions de gouvernance et de produit

Ce dossier accueille les décisions qui ne sont ni une règle de vision produit
(`docs/bible/`) ni un choix d'architecture technique (`docs/adr/`) — par
exemple : le choix d'un mode de collaboration entre les outils utilisés sur ce
projet, une décision de séquencement entre deux pull requests, ou un arbitrage
de gouvernance qui mérite de survivre au-delà d'une conversation ponctuale.

La distinction avec `docs/adr/` : un ADR répond à *comment le système est
construit*. Une entrée ici répond à *comment le projet est mené*, quand ce
n'est pas déjà couvert par `docs/CHARTER.md`.

Encore vide : la charte (`docs/CHARTER.md`) couvre à ce stade l'essentiel des
règles de gouvernance déjà stabilisées. Ce dossier accueillera les décisions
plus ponctuelles à mesure qu'elles se présentent.
