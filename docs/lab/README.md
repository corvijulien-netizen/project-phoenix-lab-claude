# Lab — Camino Virtuel

Le Lab est l'espace d'exploration visuelle et conceptuelle du projet — l'opposé
du Design System (`docs/design-system/`), qui ne contient que du validé.

## Règles

- **Le Lab est réservé aux explorations.** Une piste graphique, une idée
  d'animation, un essai de palette ou de composant qui n'a pas encore été
  validé vit ici, pas dans le Design System.
- **Les concepts peuvent évoluer librement.** Rien ici n'est figé ; une
  exploration peut être reprise, contredite ou abandonnée sans conséquence
  sur le site.
- **Rien du Lab ne doit être utilisé directement sur le site.** Une ressource
  du Lab ne devient utilisable qu'après validation explicite et migration vers
  `docs/design-system/`.

## Structure

| Dossier | Contenu |
| --- | --- |
| `concepts/` | Pistes conceptuelles, encore à l'état d'idée |
| `explorations/` | Essais visuels ou fonctionnels en cours d'évaluation |
| `archives/` | Explorations abandonnées ou remplacées, conservées pour mémoire |

Ces dossiers sont créés vides : aucune exploration n'y a encore été déposée.
