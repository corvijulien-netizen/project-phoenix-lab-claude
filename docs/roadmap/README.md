# Feuille de route

Ce dossier accueillera les fonctionnalités prévues mais pas encore construites,
et leur séquencement.

Pour une synthèse déjà établie de ce qui reste à cadrer avant d'être codé —
comptes visiteurs, tampons communautaires, moments secrets, jumeau numérique
évolutif, Knowledge Graph complet — voir `docs/bible/chapitre-1-vision.md`,
§16, en attendant qu'une feuille de route détaillée prenne le relais ici.

Encore vide : au moment où ce dossier est créé, le séquencement précis de ces
fonctionnalités n'est pas encore arrêté.
