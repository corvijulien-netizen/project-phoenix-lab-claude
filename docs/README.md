# Documentation — Camino Virtuel

Ce dossier est la mémoire écrite du projet : la vision, la manière de
travailler, et les décisions techniques qui ne doivent pas rester uniquement
dans l'historique d'une conversation.

| Dossier / fichier | Répond à la question |
| --- | --- |
| [`bible/`](bible/) | Qu'est-ce que Camino Virtuel, et pourquoi existe-t-il ? |
| [`CHARTER.md`](CHARTER.md) | Comment le projet est mené, qui décide quoi ? |
| [`adr/`](adr/) | Pourquoi telle décision d'architecture technique a été prise ? |
| [`architecture/`](architecture/) | Comment le site fonctionne, aujourd'hui ? |
| [`roadmap/`](roadmap/) | Qu'est-ce qui est prévu, mais pas encore construit ? |
| [`decisions/`](decisions/) | Quelles décisions de gouvernance ou de produit ont été prises, hors Bible et hors ADR ? |

En cas de désaccord entre un document et le code : la Bible fait foi pour la
vision produit, la charte fait foi pour la méthode de travail. Un document
qui contredirait le code doit être corrigé — ou le code, selon lequel des deux
reflète la décision réellement validée.
